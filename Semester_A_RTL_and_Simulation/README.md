# Semester A: RTL Design & Functional Verification

## 🎯 Semester Objectives
The primary goal of this phase was to develop a strong foundation in **RTL (Register-Transfer Level) coding using VHDL** and to establish rigorous verification methodologies. 

Before touching actual physical hardware, it is critical to ensure that the logic is flawlessly designed and thoroughly verified. In this semester, I operated exclusively in the simulation domain (using ModelSim/Questa), writing structural and behavioral VHDL code, and developing comprehensive testbenches.

## 📈 Chronological Progression

1. **Combinational Logic:** Understanding basic VHDL syntax, concurrent statements, and designing fundamental gates (Decoders, Multiplexers, ALUs) without clock dependency.
2. **Sequential Logic:** Introducing the clock signal. Designing D-Flip-Flops, Registers, and understanding the critical differences between asynchronous and synchronous Resets.
3. **Counters & Timers:** Designing parametric counters, cascading counters, and understanding the generation of Terminal Count (TC) signals.
4. **Basic Finite State Machines (FSM):** Introduction to state transitions and state encoding techniques.

## 🛠️ Key Takeaways
* Strict adherence to synchronous design rules.
* Separation of Datapath and Control logic.
* Writing self-checking testbenches for accurate Verification and Validation (V&V).
* Avoiding "Delay Design" and "Glitch Design" mentalities in RTL.
