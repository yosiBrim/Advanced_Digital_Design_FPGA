# Lab 05 Documentation: Synthesis & Resource Analysis

This directory contains the formal requirements, preparation analysis, and the final synthesis results for the Counter implementation on Xilinx Artix-7.

## 📁 Included Documents

* **`Ex05-Counter_Synthesis.pdf`**: Official lab specifications, including target device details (Artix-7 15T) and timing constraints.
* **`Lab05_Pre_Lab_Analysis.pdf`**: Preliminary hardware estimation, identifying inferred registers and combinational logic before the synthesis process.
* **`Lab05_Final_Synthesis_Report.pdf`**: The complete submission report containing RTL/Technology schematics and resource utilization summaries.

## 🎯 Key Learning Objectives
* Understanding the transformation from VHDL code to physical FPGA primitives (LUTs and Flip-Flops).
* Analyzing the impact of design scaling (4-bit vs. 64-bit) on hardware area.
* Verifying timing closure for a 100MHz clock frequency.
