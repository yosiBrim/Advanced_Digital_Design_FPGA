# 4-bit Counter Synthesis Results

This directory contains the physical implementation results for the 4-bit synchronous counter.

## 📊 Performance & Area
* **Resources:** Analysis of the 4 Flip-Flops and associated logic gates.
* **Timing:** Verification of the 100MHz clock constraint.

## 🔍 Visualizations
* **RTL View:** The logical structure of the 4-bit counter.
* **Technology View:** Mapping to Artix-7 primitives (FDCE, LUT).
