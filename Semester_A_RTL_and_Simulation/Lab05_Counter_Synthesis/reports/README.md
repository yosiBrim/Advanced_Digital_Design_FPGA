# Synthesis Reports (Precision RTL)

This directory contains the output reports generated by Mentor Graphics Precision during the synthesis of the counter modules targeting the **Xilinx Artix-7 (15T)** FPGA.

## 📄 Report Types
1. **Area Reports (`*_area.rep`)**: Details the exact number of hardware primitives consumed by the design (e.g., LUTs, FDCE Flip-Flops, I/O buffers).
2. **Timing Reports (`*_timing.rep`)**: Verifies that the design meets the target clock frequency constraint of **100 MHz (10ns period)**, detailing the critical path delays and slack.

By comparing the 4-bit and 64-bit reports, one can observe the direct correlation between VHDL vector widths and physical silicon utilization.
