# Lab 01 Documentation: Entities & Syntax

This directory contains the formal requirements and the final submission report for the first lab in the Advanced Digital Design course.

## 📁 Included Documents

* **`Ex01-VHDL_Entities.pdf`**: Official lab requirements and specifications provided by the faculty.
* **`Lab01_Final_Report.pdf`**: The completed assignment report, detailing the VHDL entity declarations for the requested logic and cryptographic components.

## 🎯 Objectives Covered
* Formal translation of hardware datasheets to VHDL `ENTITY` blocks.
* Verification of VHDL identifiers and naming constraints.
* Proper use of the `IEEE.STD_LOGIC_1164` library.
