# RTL Design - Lab 03

This directory contains the Design Under Test (DUT) for the testbench simulation exercise.

## 📂 Design Files
* **`nnn.vhd`**: A simple combinational Inverter (NOT gate).

## 🛠️ Implementation Details
The module is implemented using a simple concurrent signal assignment. While the logic is basic, it serves as the foundation for learning how to instantiate and map components within a more complex VHDL hierarchy.

**Port Specification:**
* `A` (Input): Logic level to be inverted.
* `Y` (Output): The logical NOT of input A.
