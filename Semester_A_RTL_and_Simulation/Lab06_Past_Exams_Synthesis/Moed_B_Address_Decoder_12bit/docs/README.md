# Moed B: Official Project Documentation

Full report and technical specifications for the 12-bit address decoder.

## 📁 Included Documents
* **`Moed_B_Decoder_Report.pdf`**: The complete design document, including VHDL analysis, synthesis logs, and schematic captures.

## 🎯 Project Goals
The main objective was to implement an efficient address decoding logic that can handle medium-width buses (12-bit) and perform range-based selection for memory-mapped systems.
