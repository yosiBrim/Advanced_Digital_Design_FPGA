# Moed A: 4-bit ALU Documentation

This directory contains the formal report for the 4-bit Arithmetic Logic Unit design.

## 📁 Files
* **`Moed_A_ALU_Report.pdf`**: Full project documentation including VHDL source, RTL/Technology schematics, and area utilization analysis.

## 🎯 Design Focus
Implementation of arithmetic (Addition) and logical (AND, OR, XOR) operations within a single combinational block using a VHDL `process` and `case` statement.
