# 📚 Project Documentation & Reference Materials

This directory contains all the foundational materials, theoretical background, and hardware specifications required for the development of this FPGA project.

## 📁 Directory Structure

* **/course_materials/**: Contains the academic syllabi and comprehensive lecture summaries covering advanced VHDL syntax, sequential/combinational logic structures, and digital design methodologies.
* **/datasheets/**: Contains the official hardware reference manuals and schematics used to map the FPGA constraints (XDC) and interface with external peripherals, including:
  * Digilent Basys 3 FPGA Board Reference Manual & Schematics
  * PmodSSD (Seven Segment Display) Reference Manual & Schematics
