# Synthesis & Implementation Reports

This directory visualizes the hierarchical synthesis of the digital clock.

### 📊 Included Visuals
* **RTL Hierarchical Schematic:** Demonstrates the top-level integration of the time base, the three cascaded counters, and the display multiplexer.
* **Vivado Device View:** Physical verification of the routing from the internal Artix-7 logic cells to the external 7-segment display pins.
