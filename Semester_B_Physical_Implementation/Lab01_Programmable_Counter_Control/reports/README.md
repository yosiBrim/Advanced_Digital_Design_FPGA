# Synthesis Reports & Logs

This directory contains the output files generated by Mentor Graphics Precision RTL during the logical synthesis phase.

## 📄 File: `precision.log`
The synthesis log file captures the step-by-step compilation, optimization, and mapping of the VHDL behavioral code (`cntr.vhd`) into hardware primitives.

### 📊 Synthesis Highlights:
* **Clock Domain Extraction:** Precision RTL correctly identifies `CLK` as the primary clock domain.
* **Technology Mapping:** The 7-bit adder logic and the equality comparator (`Q = 0`) are successfully mapped to the target technology's LUTs and Flip-Flops.
* **Timing Estimation:** Initial static timing analysis is performed to ensure no major combinational delays exist in the `TC` generation path.
